## 一、需求归类：PRD 已定义 vs 全新业务域

### 1.1 需求清单逐条归类

| # | 用户需求 | PRD v1.1 对应 | 归类 | 说明 |
|---|---|---|---|---|
| R1 | 茶具茶器板块 | **无** | 全新业务域 | PRD 六大茶类模块中无「茶具」板块，属于知识扩展新域 |
| R2 | 茶叶产地板块 | **无**（MVP 产地仅做筛选维度） | 全新业务域 | MVP 产地是 `teas.origin` 字段（省级+产区文本），无独立的产地知识板块 |
| R3 | 茶叶文化板块 | PRD §4.1 小贴士有「历史典故」单字段 | 部分已定义 | MVP 小贴士 `tea_tips.history` 是茶品级的历史典故，「茶叶文化」是跨茶品的文化知识板块，新域 |
| R4 | 茶叶品牌板块 | **无** | 全新业务域 | PRD 无品牌实体 |
| R5 | 茶叶知识板块（茶叶标准/冲泡知识/视频欣赏三子栏目） | PRD S11「用户投稿科普」+ S7「小贴士预览」 | 部分预定义 | S11 是用户投稿机制，S7 是首页预览；「茶叶知识」是管理员维护的结构化知识板块，新域 |
| R6 | 茶品详情页增加视频介绍 | **PRD S5** | ✅ 已定义第二阶段 | PRD §6 明确："独立视频播放区，支持 mp4，时长 ≤ 3 分钟"；规格已存在 |
| R7 | 首页增加图片滚动背景 | **无** | 全新视觉改造 | PRD §3 首页 Hero 区无滚动背景；PAGE_SPECS P1 无此区块设计 |
| R8 | 六大茶类及每款茶配上真实实拍图片 | PRD §4.1 「主图」必填 + **PRD S4 图片集** | 部分已定义 | MVP 已要求主图必填但种子数据用了外链 CDN；S4 是图片集（多张）；「真实实拍」是素材质量要求 |

### 1.2 归类汇总

| 类别 | 需求编号 | 数量 |
|---|---|---|
| **PRD 第二阶段已有规格** | R6（S5） | 1 |
| **PRD 有部分定义但需扩展** | R3（tea_tips.history → 独立文化板块）、R5（S7/S11 → 独立知识板块）、R8（主图 → 实拍+图片集） | 3 |
| **PRD 完全无定义的全新业务域** | R1、R2、R4 | 3 |
| **PRD 无定义的视觉改造** | R7 | 1 |
| **合计** | | 8 |

### 1.3 关键判定

1. **R6（详情页视频）= PRD S5**，规格已在 PRD §6 完整定义，但 DATA_MODEL.md §10 明确标注"S4/S5 第二阶段不建表"，说明 S5 需要新增列（`teas.video_url` 等）但不单独建表。

2. **全新业务域（R1/R2/R4/R5）**意味着需要新增表、新 API 端点、新前端页面。这些在 PRD 中完全没有提到，属于产品范围扩展。

3. **R7（首页滚动背景）**属于视觉层改造，不涉及业务规则变更，但需要确认不破坏「清新水墨」设计规范。

4. **R8（真实实拍图片）**是素材准备任务，不涉及代码变更，但种子数据（`database/init.sql`）的主图外链需替换为本地实拍图或占位图。

## 三、分级判定总表

| 需求 | 影响范围 | 分级 | 核心理由 |
|---|---|---|---|
| R1-R5 全新内容板块 | 新增表 + 新 API + 新页面 + PRD 扩展 | **C** | 触碰数据模型与 API 契约冻结规则；属于产品范围扩展 |
| R6 详情页视频（S5） | `teas` 表增列 + TeaDetail Schema 增字段 + 详情页改造 | **C** | 触碰表结构与 API 契约；虽然 PRD 已有 S5 规格，但 DATA_MODEL 明确不建 |
| R7 首页滚动背景 | 首页 Hero 区块视觉重构 | **B** | 不触碰业务规则、表结构、API 契约、安全控制；设计规范已冻结需方案对齐 |
| R8 真实实拍图片 | 素材替换 + 详情页图片集 | **C + A** | 图片集（S4）涉及表结构 → C 类；素材准备本身是 A 类 |

**汇总**：7 项需求中 5 项（或 5.5 项）涉及 C 类，必须先写提议 ADR 等待用户确认，再推进任何编码。
