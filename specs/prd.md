## 1. 背景与目标

### 1.1 问题背景

中华茶文化源远流长，六大茶类（绿、白、黄、红、乌龙、黑茶）体系庞大、品类繁多。茶爱好者在接触新茶时面临以下困境：

- **信息碎片化**：茶叶知识散落在百度、知乎、公众号中，说法不一，缺乏统一的结构化整理；
- **对比困难**：想同时看两款茶的产地、外形、汤色、冲泡参数，需要来回翻多个页面，无法并置对比；
- **入门门槛高**：新手面对"发酵程度""杀青温度""萎凋时长"等术语无从下手，需要基础科普辅助；
- **无法沉淀个人品味**：想记录自己喝过的茶、喜欢的茶、品鉴笔记，没有合适的工具。

### 1.2 产品决定

打造一个面向茶爱好者的 **六大茶类结构化知识库平台**，核心价值：

- 给每一款茶建立一张**标准化的"图鉴卡片"**，让茶的信息一目了然；
- 通过**多条件筛选 + 热门推荐 + 随机发现**三条路径，让用户轻松找到想了解的茶；
- 给用户提供**收藏清单**和**品鉴笔记**功能，沉淀自己的品茶品味；
- 支持**用户贡献**新茶和科普内容，让知识库越用越丰富（第二阶段）。

### 1.3 预期可观察结果

- 用户在三分钟内可以找到"浙江产的明前绿茶"并完成一次浏览；
- 注册用户可以创建收藏清单，支持链接分享；
- 平台上线三个月后，用户贡献的新茶数据和科普小贴士数量超过官方初始数据。

## 2. 功能分级总览

> 本章是对全部功能点的决策性分级，下游开发以本章为准。各功能模块的详细规格在第 4 章给出，其中「MVP 范围内」与「第二阶段」的边界以本章标记为依据。

### 2.1 MVP（第一版，必须实现）

缺了任何一项，"发现茶 → 看详情 → 收藏/分享"走不通。

| 编号 | 模块 | 核心交付 |
|---|---|---|
| M1 | 茶图鉴卡片 — 数据模型 | 字段定义 + 数据库存储，官方可录入 |
| M2 | 茶品列表页 + 筛选 | 卡片视图、基础 3 维筛选（茶类/产地/季节）、AND 逻辑、分页 |
| M3 | 首页发现入口 | 六大茶类导航、热门推荐（总量排序）、随机发现、搜索框 |
| M4 | 茶品详情页 | 结构化数据展示、官方小贴士、收藏/写笔记/分享按钮入口 |
| M5 | 注册登录 | 用户名密码注册/登录、会话保持、登录回流到触发页 |
| M6 | 收藏清单 + 品鉴笔记 + 分享链接 | 单清单（默认"我的收藏"）、品鉴笔记、链接分享、撤销分享 |
| M7 | 管理员后台（官方数据维护） | 新增/编辑茶品、上下架、发布官方小贴士 |

### 2.2 第二阶段（有价值但不影响 MVP 闭环）

MVP 跑起来后按优先级逐个补充。

| 编号 | 功能 | 分级理由 |
|---|---|---|
| S1 | 列表页 OR 条件切换 | 90% 用户只用默认 AND，增加 DB 查询复杂度 |
| S2 | 筛选维度扩展至 5 档全开（加发酵程度、价格区间） | 多几个下拉，数据质量够了自然能开 |
| S3 | 列表页"六大摘要"对比视图 | 单款详情已解决大部分浏览需求，对比视图锦上添花 |
| S4 | 详情页图片集 + 缩略图切换 | 单张主图已够用，多图需要额外存储 |
| S5 | 详情页视频播放区 | 存储成本高，MVP 官方数据大概率无视频素材 |
| S6 | 详情页相关推荐（同茶类/同产地） | 首页的热门+随机已做发现，详情页推荐重复价值 |
| S7 | 首页"科普小贴士最新"预览 | 首页核心是发现，科普嵌在详情页即可 |
| S8 | 分享图片海报（前端生成 + 二维码） | 链接分享已闭环，海报需要图形库 + 设计素材 |
| S9 | 创建多个收藏清单（按主题分类） | 默认清单一个已够用，分类是高级玩法 |
| S10 | 用户贡献 — 补充新茶（含双层校验机制） | 需维护名品-茶类映射表 + 管理员审核后台，工程量大 |
| S11 | 用户贡献 — 投稿科普 + 审核 | 同上，依赖管理员审核流程 |
| S12 | 管理员审核后台（提交队列 + 拒绝理由预设） | 用户贡献的配套，没贡献就不需要审核 |
| S13 | 我的提交记录（用户端追踪审核状态） | 用户贡献的配套 |
| S14 | 密码错误 5 次锁定 15 分钟 | MVP 用户量小，安全风险低 |
| S15 | 用户等级展示（含档位名称） | 等级值依赖贡献数据，MVP 没开放贡献就没等级意义 |
| S16 | 随机发现 → 基于收藏偏好推荐 | MVP 完全随机能跑，个性化需用户行为数据积累 |
| S17 | 热门推荐算法升级（7 天热度权重） | MVP 总量排序够用，用户多了才需增量计算 |

### 2.3 暂不实现（当前成本高或无必要）

| 编号 | 功能 | 原因 |
|---|---|---|
| X1 | 用户等级差异化权益 | 等级档位还没定，权益更无从谈起；等用户量上来再设计 |
| X2 | 冲泡参数分器具对比（盖碗/玻璃/紫砂） | 先放一组基础数据，不是结构化图鉴的核心 |
| X3 | 每日一茶 + 打卡签到 | 需要定时任务 + 打卡状态持久化，MVP 没这个运营节奏 |
| X4 | 忘记密码（邮箱重置） | 需接邮箱服务，MVP 提示"联系管理员"成本更低 |
| X5 | 手机号/微信扫码登录 | 需对接第三方 SDK + 资质，MVP 用户名密码够用 |
| X6 | 产地筛选细化到市/产区 | 官方数据初期按省级录，后续根据数据覆盖扩展 |
| X7 | 用户投稿支持富文本 + 图片 | 富文本编辑器增加复杂度，图片涉及内容安全审核 |
| X8 | 管理员管理用户账号（封禁/删除） | MVP 用户量小，滥用风险低 |
| X9 | 搜索"相关度"排序的完整 TF-IDF | 小数据集下简单关键词匹配够用 |
| X10 | 茶叶电商、交易、支付 | 不在产品契约内 |
| X11 | 在线茶艺直播或视频课程平台 | 不在产品契约内 |
| X12 | AI 智能问答或聊天机器人 | 不在产品契约内 |
| X13 | 移动端 App | 不在产品契约内（仅响应式 Web） |

### 2.4 产品契约（不变）

| 项 | 定义 |
|---|---|
| **主要用户** | 茶爱好者（含新手入门者和资深茶客） |
| **核心任务** | 查找、浏览、记录自己感兴趣的茶 |
| **触发条件** | 用户打开首页 / 访问特定茶类 / 搜索某款茶 |
| **完成条件** | 用户完成一次"发现茶 → 查看详情 → 收藏/写笔记/分享"的闭环 |
| **共享对象** | 茶叶图鉴卡片、收藏清单 |

### 2.5 MVP 最小完整旅程

| 编号 | 能力 | 入口条件 | 用户完成标志 |
|---|---|---|---|
| MVP-1 | 游客浏览六大茶类及全部茶品 | 访问首页 | 看到茶品列表，可点进详情 |
| MVP-2 | 多条件筛选（茶类/产地/季节） | 进入列表页 | 筛选结果符合条件，支持 AND 叠加 |
| MVP-3 | 图鉴卡片详情页 | 点击任一茶品 | 看到结构化数据 + 官方小贴士 |
| MVP-4 | 热门推荐 + 随机发现 | 首页推荐区 | 热门按总量排序，随机可刷新 |
| MVP-5 | 注册登录（用户名 + 密码） | 点击收藏/写笔记/分享 | 完成注册或登录，回到触发页 |
| MVP-6 | 收藏 + 品鉴笔记 | 登录用户点击收藏 | 茶品进入默认清单，可写笔记 |
| MVP-7 | 分享链接（+ 撤销） | 清单页点击分享 | 生成链接，被分享者只读 |
| MVP-8 | 管理员数据维护 | 管理员后台 | 新增/编辑茶品、上下架、发布小贴士 |

## 4. 核心对象

### 4.1 茶叶图鉴卡片（MVP 字段）

#### 必填字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 茶品名称 | 文本 | 如"西湖龙井" |
| 六大茶类 | 枚举 | 绿 / 白 / 黄 / 红 / 乌龙 / 黑 |
| 产地 | 文本 | MVP 精确到省级 + 产区描述，如"浙江 杭州 西湖狮峰" |
| 外形描述 | 文本 | 干茶的形状、颜色、光泽 |
| 汤色描述 | 文本 | 冲泡后的茶汤颜色 |
| 香气描述 | 文本 | 干茶香 + 热闻香 + 冷闻香 |
| 滋味描述 | 文本 | 口感、回甘、韵味 |
| 冲泡参考：水温 | 数值 | 摄氏度，范围 70-100 |
| 冲泡参考：投茶量 | 数值 | 克 |
| 冲泡参考：浸泡时间 | 数值 | 秒 |
| 主图 | 图片 | 干茶特写照片（单张） |

#### 选填字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 代表品类 | 文本 | 该产地的典型品种，如"群体种" |
| 采摘季节 | 枚举 | 明前 / 雨前 / 春茶 / 夏茶 / 秋茶 / 冬茶 |
| 发酵程度 | 枚举 | 不发酵 / 微发酵 / 半发酵 / 全发酵 / 后发酵 |
| 价格区间 | 枚举 | 5 档 |
| 图片集 | 图片列表 | 干茶、冲泡、汤色等多角度（**第二阶段开放**） |
| 视频介绍 | 视频 | 不超过 3 分钟（**第二阶段开放**） |

#### 小贴士区（官方发布）

| 字段 | 类型 | MVP 状态 |
|---|---|---|
| 历史典故 | 文本 | ✅ 可用，空则隐藏 |
| 适合人群 | 文本 | ✅ 可用，空则隐藏 |
| 冲泡误区 | 文本 | ✅ 可用，空则隐藏 |
| 品鉴笔记（官方） | 文本 | ✅ 可用，空则隐藏 |
| 科普小贴士（用户投稿） | 文本列表 | ❌ 第二阶段开放 |

### 4.2 收藏清单（MVP 字段）

## 5. 功能需求 — MVP 范围

> 本章只描述 MVP 范围内的功能点。第二阶段的功能规格在第 6 章给出，暂不实现的功能不写规格。

### 模块 1：茶品列表页 + 筛选

#### Purpose
让用户通过结构化条件快速定位到目标茶品。

#### Layout
```
┌──────────────────────────────────────────────┐
│  面包屑：首页 / 绿茶（可切换为"全部"）        │
├──────────────────────────────────────────────┤
│  筛选面板：                                   │
│  茶类 ▾  产地 ▾  季节 ▾                      │
│  当前已选 × ×  [清除全部]                     │
├──────────────────────────────────────────────┤
│  排序：[最新上架 ▾]                           │
├──────────────────────────────────────────────┤
│  结果：共 42 款                               │
│                                              │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐           │
│  │ 主图│ │ 主图│ │ 主图│ │ 主图│           │
│  │     │ │     │ │     │ │     │           │
│  │名称 │ │名称 │ │名称 │ │名称 │           │
│  │产地 │ │产地 │ │产地 │ │产地 │           │
│  │❤️12 │ │❤️8  │ │❤️15 │ │❤️3  │           │
│  └─────┘ └─────┘ └─────┘ └─────┘           │
├──────────────────────────────────────────────┤
│  分页（第 1 页 / 共 3 页）                    │
└──────────────────────────────────────────────┘
```

#### Trigger
- 从首页点击六大茶类快速入口进入 → 筛选面板默认选中该茶类
- 从首页搜索框跳转进入 → 筛选条件由搜索词填充

#### Processing Rules

**FR-1.1 筛选维度**（仅 3 个）

| 维度 | 可选项 | 多选 |
|---|---|---|
| 六大茶类 | 绿 / 白 / 黄 / 红 / 乌龙 / 黑 | ✅ |
| 产地 | 省级选项（如"浙江""福建""云南"） | ✅ |
| 采摘季节 | 明前 / 雨前 / 春茶 / 夏茶 / 秋茶 / 冬茶 | ✅ |

**FR-1.2 条件逻辑**
- **固定 AND**：所有选中维度必须同时满足
- 同维度内多选视为 OR（如选中"绿茶 **或** 白茶"），不同维度之间仍为 AND
- **MVP 不支持 OR 跨维度切换**（S1 第二阶段）

**FR-1.3 筛选面板交互**
- 筛选结果实时更新（onChange 触发），不需要点"应用"
- 已选条件显示为标签，可单独 × 移除
- "清除全部"一键重置

**FR-1.4 排序**
- 最新上架（默认，按创建时间倒序）
- 收藏最多（总收藏数倒序）
- **MVP 不提供"相关度"排序**（X9 暂不实现）

**FR-1.5 卡片视图**
- 封面主图 + 名称 + 产地 + 收藏数（❤️ N）
- 每张卡片可点击进入详情页
- **MVP 不提供列表视图 / 六大摘要对比视图**（S3 第二阶段）

**FR-1.6 分页**
- 每页 12 款，底部显示"共 N 款 / 第 X 页 共 Y 页"
- **MVP 不做无限加载**（后续可改）

#### Exceptions

| 场景 | 处理 |
|---|---|
| 筛选无结果 | 空状态 + "试试调整筛选条件" + 3 款热门引导 |
| 某茶类下暂无茶品 | 入口卡片显示"暂无收录"，点击后空状态 |
| 产地数据为空 | 产地下拉隐藏或显示"全部" |

#### 依赖关系
- 前置：模块 7（管理员已录入茶品数据）
- 后置：模块 4（点击卡片进入详情）

### 模块 2：首页

#### Purpose

#### 依赖关系
- 前置：模块 4（收藏/写笔记/分享需登录）
- 后置：模块 5（收藏、笔记、分享的实际执行）

### 模块 4：注册登录

#### Purpose
给用户身份，解锁收藏、笔记、分享。

#### Trigger
- 游客点击任何需要身份的操作（收藏 / 写笔记 / 分享）
- 点击导航栏"我的"

#### Processing Rules

**FR-4.1 注册流程**
1. 弹出面板：用户名 + 密码
2. 用户名实时唯一校验（已占用 → 禁用提交）
3. 注册成功 → 自动登录 → **回到刚才想操作的页面**
   - 例：从详情页收藏按钮触发 → 注册成功后自动完成收藏
   - 例：从导航栏"我的"触发 → 注册成功后进入"我的"页面

**FR-4.2 登录流程**
1. 弹出面板：用户名 + 密码
2. 登录成功 → 同上，回到触发页面

**FR-4.3 会话保持**
- 登录状态默认保持 30 天（cookie）
- 退出登录按钮在"我的"页面和导航栏右上角

**FR-4.4 MVP 明确不做**
- 忘记密码（提示"请联系管理员"）
- 密码错误锁定
- 邮箱/微信扫码登录
- 用户等级展示

#### Exceptions

| 场景 | 处理 |
|---|---|
| 用户名已存在 | 实时提示，禁用提交 |
| 密码错误 | 常规错误提示（不告知是用户名错还是密码错） |
| 会话过期 | 操作时提示"登录已过期" + 弹出登录面板 |

#### 依赖关系
- 独立模块，无前置依赖
- 后置：模块 5（收藏/笔记/分享需要登录身份）

### 模块 5：收藏清单 + 品鉴笔记 + 分享链接

#### Purpose
让用户沉淀品茶品味，并传播给茶友。

#### Trigger
- 详情页/列表页/推荐区的 ❤️ 按钮
- 导航栏"我的 → 我的收藏"
- 被分享者访问分享链接

#### Processing Rules

**FR-5.1 收藏操作**
- 系统自动为每个用户创建一个**默认清单**（名为"我的收藏"，不可删除，标题可编辑）
- 已登录用户点击 ❤️ → 茶品进入默认清单，按钮变为实心 ❤️"已收藏"
- 再次点击实心 ❤️ → 取消收藏

**FR-5.2 清单页面**
- 顶部：清单标题（可编辑）
- 下方：清单内茶品列表，每条显示缩略图 + 名称 + 产地
- 每条下方：**品鉴笔记**点击打开编辑面板
- **MVP 不支持创建多个清单**（S9 第二阶段）、**不支持清单描述字段**（第二阶段）

**FR-5.3 品鉴笔记**
- 清单内每条茶品的笔记独立存储
- 仅清单所有者可编辑
- 笔记与茶品详情页的"用户投稿"是完全独立的两个东西（收藏笔记是私有的、用户投稿是公开的）

**FR-5.4 分享链接**
- 清单页点击"分享"→ 生成唯一 URL（如 `https://domain.com/c/k7X9m2`）
- 链接永久有效（除非用户手动撤销）
- 被分享者打开链接：
  - **无需登录**即可查看清单内容（只读）
  - 被分享者是登录用户 → 额外显示"一键收藏全部"按钮
  - 被分享者是游客 → 所有操作按钮隐藏，需登录

**FR-5.5 撤销分享**
- 清单所有者在清单设置中可撤销
- 撤销后原链接失效，访问显示"该分享已被撤销" + 引导浏览公开推荐
- 撤销不可逆（再分享生成新链接）

**FR-5.6 一键收藏全部**
- 仅被分享者（含登录用户）可执行，所有者自己就是清单主人不需要
- 批量加入自己的默认清单，已存在的跳过不重复

**FR-5.7 MVP 明确不做**
- 分享图片海报（S8 第二阶段）
- 清单内单条备注字段（PRD 原来的"用户备注"合并到品鉴笔记里了）
- 创建多个清单

#### Permissions

| 操作 | 清单所有者 | 被分享者（含登录用户） | 其他用户 |
|---|---|---|---|
| 查看清单 | ✅ | ✅（只读） | ❌ |
| 编辑清单标题 | ✅ | ❌ | ❌ |
| 添加/移除茶品 | ✅ | ❌ | ❌ |
| 编辑品鉴笔记 | ✅ | ❌ | ❌ |
| 撤销分享 | ✅ | ❌ | ❌ |
| 一键收藏全部 | ❌ | 登录用户可执行 | ❌ |
| 生成分享链接 | ✅ | ❌ | ❌ |

#### Exceptions

| 场景 | 处理 |
|---|---|
| 清单中茶品被管理员下架 | 清单仍保留，下架茶品显示灰色占位 + "该茶品暂不可用" |
| 被分享者通过失效链接访问 | "该分享已被撤销" + 引导浏览公开推荐 |

#### 依赖关系
- 前置：模块 3（详情页入口）、模块 4（需登录身份）
- 无后置依赖（第一阶段完成整个 MVP 闭环）

### 模块 6：管理员后台（数据维护）

#### Purpose
让管理员录入和维护官方茶品数据，支撑 MVP 前端浏览。

#### Processing Rules

**FR-6.1 新增茶品**
- 表单包含 MVP 范围内的全部必填字段（见第 4.1 节）
- 必填校验由前端 + 后端双重保障
- 选填字段允许留空

**FR-6.2 编辑茶品**
- 全部字段可编辑
- 编辑后即时生效（不需要审核，管理员是可信角色）

**FR-6.3 茶品上下架**
- 上架：全部前端可见（列表/搜索/推荐/详情）
- 下架：前端列表/搜索/推荐均不出现；已收藏的用户清单中保留占位但灰显
- 管理员可随时重新上架

**FR-6.4 发布官方小贴士**
- 4 个小贴士区块（历史典故/适合人群/冲泡误区/品鉴笔记）可分别编辑
- 每个区块可独立清空（清空后前端对应区块隐藏）

**FR-6.5 MVP 明确不做**
- 用户提交审核队列（整套 S10/S11/S12 第二阶段）
- 管理用户账号
- 批量导入数据（先手动录入，数据量上来再考虑 Excel/CSV 导入）

#### 依赖关系
- 无前置依赖（MVP 第一个跑的模块就是它）
- 后置：全部前端模块都依赖它提供数据

## 6. 第二阶段功能规格（预定义，开发时直接引用）

> 本章为第二阶段功能的规格草案，MVP 阶段不开发。规格可以在第二阶段启动时根据实际情况调整。

### S1. 列表页 OR 条件切换
- 在现有 AND 逻辑基础上，增加一个"切换为 OR"按钮
- OR 逻辑：跨维度也视为 OR（绿茶 OR 浙江产）
- 实现要点：DB 查询条件拼装从 `WHERE a AND b` 变为 `WHERE a OR b`

### S2. 筛选维度扩展
- 新增：发酵程度（5 档枚举）、价格区间（5 档枚举）
- 与现有 3 个维度统一交互样式

### S3. 列表页"六大摘要"视图
- 新增视图切换：[卡片视图] [摘要对比]
- 摘要视图：每行展示名称 + 产地 + 外形摘要 + 汤色摘要 + 香气摘要 + 滋味摘要（各字段截断到 50 字）
- 适合快速对比多款茶的感官描述

### S4. 详情页图片集
- 主图下方展示缩略图行，点击切换主图
- 至少 1 张主图，最多 9 张，单张 ≤ 5MB

### S5. 详情页视频
- 独立视频播放区，支持 mp4，时长 ≤ 3 分钟
- 视频标签展示在主图旁边

### S6. 详情页相关推荐
- 从同茶类 / 同产地 / 同发酵程度各取 2 款（不足则交叉补充）
- 排除当前茶品和下架状态
- 最多展示 6 款

### S7. 首页科普小贴士最新预览
- 热门推荐下方增加 2-3 条最新官方小贴士的标题预览
- 点击跳转到对应茶品详情页

### S8. 分享图片海报
- 分享面板增加第二个 Tab「海报」
- 海报由前端 html2canvas 生成：清单标题 + 前 6 款茶缩略图 + 名称 + 清单链接二维码 + 水印
- 提供 1-2 套预设视觉模板
- 下载为 PNG

### S9. 多清单管理
- 允许用户创建额外清单，每个清单独立设置标题、描述、可见性
- 默认"我的收藏"保留，不可删除

### S10. 用户贡献 — 补充新茶
- 提交表单与管理员新增表单结构一致，但：
  - 系统基础校验：必填完整性、类型矛盾检测（已知绿茶品种 + 茶类 ≠ 绿 → 拦截）、名称查重（相似度 > 90% → 拦截）
  - 提交后状态：待审核 → 管理员审核通过后上架 / 拒绝（附理由）
- 用户在"我的提交"查看提交状态和拒绝理由

### S11. 用户贡献 — 投稿科普
- 给已有茶品投稿：目标茶品（从详情页进入则自动选中）+ 标题（可选）+ 内容（3-500 字）
- 基础校验：字数边界、茶品必须已上架
- 提交后走审核队列

### S12. 管理员审核后台
- 审核队列分两个 Tab：新茶 / 科普投稿
- 每条展示全部内容预览 + 提交者用户名 + 提交时间
- 通过 → 新茶上架 / 科普在详情页展示
- 拒绝 → 选预设理由或自定义，拒绝理由通知用户
- 预设拒绝理由：信息不完整、茶类矛盾、重复提交、疑似广告、其他原因

### S13. 我的提交记录
- 用户端"我的 → 我的提交"
- 状态：待审核 / 已通过 / 已拒绝（附理由）
- 允许删除"待审核"状态的提交
- 拒绝后可修改重新提交（作为新条目）

### S14. 密码错误锁定
- 同一账号密码错误 5 次 → 锁定 15 分钟
- 锁定期间登录面板显示"账号已临时锁定，请稍后再试"

### S15. 用户等级
- 等级计算：贡献度（提交通过数 × 10 + 品鉴笔记数 × 2）+ 注册时长（每月 +1）
- 档位 TBD（MVP 仅后台统计，不展示）

### S16. 个性化随机发现
- 记录用户收藏过的茶类和产地
- 随机发现优先展示同茶类或同产地的茶品
- 无收藏数据时退化为完全随机

### S17. 热门推荐算法升级
- 每日凌晨计算：热度得分 = 过去 7 天查看次数 × 1 + 过去 7 天收藏次数 × 3
- 按得分排序取前 8
- 初期数据不足时退化为总量排序

| Q-05 | 导航栏"我的"在未登录时展示什么？ | 建议：点击直接触发注册/登录面板，登录后展示个人中心（收藏 + 我的提交（第二阶段）+ 设置） |
